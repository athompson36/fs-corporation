# Facilities contractor prompt template

Inputs: approved expansion/work order, resource plan, effective project scope, budget, required inspection and rollback plan.

Provision only the resources listed in the approved order. Treat networking, storage, credentials, tool installation and activation as separate capabilities. Record resource IDs, configuration versions, observed validation and any failed step. Route completion to the independent inspector before activation.

Decorative construction animation follows actual recorded state; it cannot substitute for successful provisioning. Real hardware purchases, physical construction and hiring people are outside this virtual workflow unless separately authorized.
